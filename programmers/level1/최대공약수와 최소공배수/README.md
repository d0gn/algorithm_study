# 문제 설명
두 수를 입력받아 두 수의 최대공약수와 최소공배수를 반환하는 함수, solution을 완성해 보세요. 배열의 맨 앞에 최대공약수, 그다음 최소공배수를 넣어 반환하면 됩니다. 예를 들어 두 수 3, 12의 최대공약수는 3, 최소공배수는 12이므로 solution(3, 12)는 [3, 12]를 반환해야 합니다.

제한 사항
두 수는 1이상 1000000이하의 자연수입니다.

# 문제 풀이

파이썬 라이브러리 math 의 함수 gcd(최대 공약수 구하는 함수), lcm(최소 공배수 구하는 함수)
사용방법
gcd(정수 a, 정수 b) : 정수 a, b 의 최대 공약수를 구해줌
lcm(정수 a, 정수 b) : 정수 a, b 의 최소 공배수를 구해줌


#직접 구현
최대공약수 (유클리드 호제법)
def gcd(a, b):
    while b:
        a, b = b, a % b
    return a

최소공배수
def lcm(a, b):
    return (a * b) // gcd(a, b)

테스트
a, b = 12, 18
print("최대공약수:", gcd(a, b))  # 6
print("최소공배수:", lcm(a, b))  # 36
