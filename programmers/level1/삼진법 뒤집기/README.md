# 문제 설명
자연수 n이 매개변수로 주어집니다. n을 3진법 상에서 앞뒤로 뒤집은 후, 이를 다시 10진법으로 표현한 수를 return 하도록 solution 함수를 완성해주세요.

제한사항
n은 1 이상 100,000,000 이하인 자연수입니다.

# 문제 풀이

해당 문제는 3진법을 구한뒤 해당 3진법의 역순을 10진법으로 구한 수를 찾아야한다 나의 풀이는
코드의 주석에서도 나와 있듯 3의 배수를 늘려가면서 n 보다 3의 배수가 값이 커질때의 값을 저장후
이후 해당값을 n에 몫 나누기를 이용하여 str에 3진법을 저장한다 이후 슬라이싱을 통해 역순으로 정렬하고
역순 순서대로 값을 곱해가며 결과를 구했다
하지만 이는 구현에서 매우 나쁜 효율을 갖고 있다

코드 하단의 주석으로 처리된 부분을 보면
먼저 반복문을 통해 진법의 수만큰 나머지를 str 에 추가한다 (역정렬을 바로 실시해버리는 경우)
이후 n을 n = n // 3 통해 다음 값을 구한다
이를 반복하면 n 은 몫이 반드시 0 이되는 경우가 발생한다
이때 반복문이 종료 됨으로 써 역순으로 정렬된 3진법을 구하게 된다
** 또한 int()함수를 통해 형변환과 동시에 2번째 파라미터에 정수를 넣어 
int(문자열, 진법) 해당 문자열이 몇 진법인지 까지도 입력해주면 해당 진법에 따라 10진수로 계산해서 정수로 반환해준다.
