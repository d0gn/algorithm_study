# 문제 설명
문제 설명
문자열 s에는 공백으로 구분된 숫자들이 저장되어 있습니다. str에 나타나는 숫자 중 최소값과 최대값을 찾아 이를 "(최소값) (최대값)"형태의 문자열을 반환하는 함수, solution을 완성하세요.
예를들어 s가 "1 2 3 4"라면 "1 4"를 리턴하고, "-1 -2 -3 -4"라면 "-4 -1"을 리턴하면 됩니다.

제한 조건
s에는 둘 이상의 정수가 공백으로 구분되어 있습니다.

# 문제 풀이

문자열을 잘라내야 함으로 파이썬의 split 함수를 사용하여 공백을 기준으로 쉽게 잘라낼 수 있다 잘라냄과 동시에 int형으로 변환해준다.
(파이썬 함수를 사용하지 않으면 문자열의 문자를 하나씩 검사하여 공백일때 앞서 쌓인 문자열을 리스트에 저장한다)
이후 큰값과 작은값 구분을 위해 min(), max() 함수를 활용하여 큰값과 작은값을 구분한다 str 형태일때 min(), max() 또한 사용가능하나
큰 값을 작은값으로 작은값을 큰 값으로 인식해버린다
min() 결과 = -1,max() 결과 = -4 가 되어버리기 때문에 int 형으로 미리 변환해두는것
이후 큰값과 작은값을 문자열에 공백과 함깨 문자열에 담기위해 str 형으로 변환하고 동시에 공백을 삽입함으로써 문제를 해결한다
