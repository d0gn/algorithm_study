# 문제 설명
Finn은 요즘 수학공부에 빠져 있습니다. 수학 공부를 하던 Finn은 자연수 n을 연속한 자연수들로 표현 하는 방법이 여러개라는 사실을 알게 되었습니다. 예를들어 15는 다음과 같이 4가지로 표현 할 수 있습니다.

1 + 2 + 3 + 4 + 5 = 15
4 + 5 + 6 = 15
7 + 8 = 15
15 = 15
자연수 n이 매개변수로 주어질 때, 연속된 자연수들로 n을 표현하는 방법의 수를 return하는 solution를 완성해주세요.

제한사항
n은 10,000 이하의 자연수 입니다.

# 문제 풀이

2중 반복문을 이욯애서 첫 반복문은 2번째 반복문의 시작 값으로 설정한다
이후 반복문에서 값을 계속 더해 가면서 n 값이랑 일치하면 카운트를 추가하고 break
다음 반복이 시작되어 값을 더해간다
하지만 값이 일치하지 않고 계속 더해지는 경우가 있는데 이때 반드시 temp 값이 n 값보다 커지는 경우를 대비한 break 를 넣어 두어야한다
안그러면 시간 효율이 너무 나빠지기 때문. 2중 반복문 자체가 시간표기 제곱이므로 좋지 않다

그래서 조사를 해본 결과 

수학적으로 어떤 자연수를 연속된 자연수의 합으로 나타내는 방법의 수는 그 수의 홀수인 약수의 개수와 정확하게 같다라고 한다.
그러므로 
range(1, n+1, 2) 를 통해 홀수값을 나열하고 if 문을 통해 n 과 나누었을때 나머지가 0인 경우에만 리스트에 넣고
리스트의 길이 (약수의 개수)를 구하는 방법도 있다.

len([i for i in range(1, n + 1, 2) if n % i == 0])
