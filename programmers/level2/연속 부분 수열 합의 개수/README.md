# 문제 설명
철호는 수열을 가지고 놀기 좋아합니다. 어느 날 철호는 어떤 자연수로 이루어진 원형 수열의 연속하는 부분 수열의 합으로 만들 수 있는 수가 모두 몇 가지인지 알아보고 싶어졌습니다. 원형 수열이란 일반적인 수열에서 처음과 끝이 연결된 형태의 수열을 말합니다. 예를 들어 수열 [7, 9, 1, 1, 4] 로 원형 수열을 만들면 다음과 같습니다.
그림.png
원형 수열은 처음과 끝이 연결되어 끊기는 부분이 없기 때문에 연속하는 부분 수열도 일반적인 수열보다 많아집니다.
원형 수열의 모든 원소 elements가 순서대로 주어질 때, 원형 수열의 연속 부분 수열 합으로 만들 수 있는 수의 개수를 return 하도록 solution 함수를 완성해주세요.

제한사항
3 ≤ elements의 길이 ≤ 1,000
1 ≤ elements의 원소 ≤ 1,000

# 문제 풀이

반복문을 통해 수열을 구하려면 전체 수열에서 1부터 수열의 길이만큼 각각 합을 구해야함
그래서 일반적으로 묶이는 수를 기준으로 하는게 아니라 처음부터 1부터 n 묶음까지 계속 구해간다
이를위해 배열을 2배 연장하여서 [7,9,1,1,4,7,9,1,1,4] 이렇게 만들고
코드대로 반복을 실행하면 
9,1,1,4,7 배열에서 1~2, 2~3, 3~4, 4~5 이렇게 두개 값을 묶는다
이후 다음 반복문에서는 size 값이 커져서 1~3, 2~4, 3~5 이런식으로 묶음이 늘어남
이를 set()을 사용하여 중복된 값을 제거한다 set()은 중복된 값을 허용하지 않는 특징을 이용한다
이후 해당 값의 길이만큼이 부분수열의 중복되지 않는 값의 갯수이다.
