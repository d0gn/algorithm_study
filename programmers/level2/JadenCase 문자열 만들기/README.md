# 문제 설명
문제 설명
JadenCase란 모든 단어의 첫 문자가 대문자이고, 그 외의 알파벳은 소문자인 문자열입니다. 단, 첫 문자가 알파벳이 아닐 때에는 이어지는 알파벳은 소문자로 쓰면 됩니다. (첫 번째 입출력 예 참고)
문자열 s가 주어졌을 때, s를 JadenCase로 바꾼 문자열을 리턴하는 함수, solution을 완성해주세요.

제한 조건
s는 길이 1 이상 200 이하인 문자열입니다.
s는 알파벳과 숫자, 공백문자(" ")로 이루어져 있습니다.
숫자는 단어의 첫 문자로만 나옵니다.
숫자로만 이루어진 단어는 없습니다.
공백문자가 연속해서 나올 수 있습니다.

# 문제 풀이

문제에서 제시한 문자열을 split 함수를 사용해 단어를 쪼개어 리스트로 저장한다 이후 원소 단어 하나씩 꺼내어
capitalize() 함수를 사용하여 (첫글자만 대문자 나머지 소문자로 변환 함) 리스트에 저장해두고
join을 통하여 리턴하면 됨
capitalize()를 사용하지 않으려면 문자열 슬라이싱을 통해 첫 문자는 upper() 적용 이후 나머지 문자는 lower()를 적용시켜 리스트에 저장후
join을 사용하여 리턴하면 됨.
